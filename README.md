## Running Locally


```sh-session
git clone https://github.com/DGRTFR/PortfolioV2.git
cd PortfolioV2
```


Create a `.env` file similar to [`.env.example`](https://github.com/Friezer-85/PortfolioV2/blob/main/.env.example).

Then install dependencies and run the development server:
```sh-session
pnpm install
pnpm dev
```
